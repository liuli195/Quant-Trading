# 量化交易项目

这是一个量化交易项目，基于 python ，主要用于A股股票和场内基金。
该项目在聚宽的云平台<<https://www.joinquant.com上进行开发和测试，无法在本地运行。>
该项目采用聚宽API：<https://www.joinquant.com/help/api/help#name:api> 来进行数据获取，策略编写，模拟交易等操作。
该项目采用聚宽提供的策略回测系统:<https://www.joinquant.com/algorithm/index/list> 进行策略的回测。
该项目采用聚宽提供的模拟交易系统:<https://www.joinquant.com/algorithm/trade/list> 进行策略的模拟交易。
该项目目前暂未进入实盘阶段。
