# 聚宽策略回测

***注意*** 提供给用户复制的代码需要过滤掉注释，本地策略文件要保留注释

## 1. 读取策略文件

读取用户指定的策略文件 → 如用户指定进行性能分析，则添加性能分析代码 → 展示完整代码给用户，供用户进行复制

## 2. 用户操作：打开编辑页、粘贴代码、编译运行

## 3. 检查编译结果并修复错误

- 读取日志和错误
- 无 ERROR：进入下一步
- 有 ERROR：先修复本地文件 → 将修正后代码提供给用户重新粘贴编译 → 重复直到无错误

## 4. 用户操作：设置回测参数、运行回测

## 5. 提取结果

- 提取核心指标：策略收益/年化收益、基准收益、Alpha、Beta、Sharpe、Sortino、最大回撤及区间、胜率、盈亏比、超额收益、信息比率
- 表格呈现 + 简要分析

## 6. 性能分析（用户指定时执行）

-提取性能分析报告
-表格呈现 + 简要分析 + 优化策略
