# 聚宽策略回测

## 1. 读取策略

- 读取用户指定的策略文件
- 如用户指定性能分析，则插入性能分析代码

## 2. 上传编译

- 通过 MCP Chrome 打开聚宽策略编辑页面
- 粘贴代码到编辑器（去除所有注释），选择一天回测范围后编译

## 3. 修复错误

- 有 ERROR → 修复本地文件后重新上传编译 → 循环至无错误

## 4. 运行回测

- 按用户要求设置回测起止日期和初始资金
- 用户未指定时默认近一周，初始资金 50 万
- 正式运行回测

## 5. 策略分析

- 等待回测结束，提取核心指标
- 核心指标：策略收益/年化收益、基准收益、Alpha、Beta、Sharpe、Sortino、最大回撤及区间、胜率、盈亏比、超额收益、信息比率
- 表格呈现 + 简要分析 + 优化建议
- 结果更新入 `strategies/{策略文件名}_Analysis.md`

## 6. 性能分析（用户指定时执行）

- 提取性能分析报告
- 表格呈现 + 简要分析 + 优化建议
- 结果更新入 `strategies/{策略文件名}_performance.md`
