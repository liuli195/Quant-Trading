# JQ AB Test 流程

## 阶段一：实验设计校验

对 AB 配置运行 4 条规则。未通过项输出具体问题、严重性、修复方向。

## 阶段二：执行

1. baseline 先跑，variant 依序跑。
2. 任一变体失败时记录错误，继续下一个。
3. 所有回测完成后检查状态完整性。

## 阶段三：Delta 归因

1. 读取 baseline 和 variant 的 `summary_metrics.json` + `all_data.json`。
2. 计算总差异表：年化收益差、Sharpe 差、最大回撤差、换手差、平均仓位差。

### 收益差分解（会计法）

```
总收益差 = 暴露差异 + 换手差异 + 因子暴露差异 + 交互效应
```

- **暴露差异**：variant 平均仓位 - baseline 平均仓位，乘以 baseline 选股收益，解释"仓位高低"贡献。
- **换手差异**：variant 年化换手 - baseline 年化换手，按 0.1% 单边成本估算交易成本影响。
- **因子暴露差异**：variant 在各风格因子上的平均暴露 - baseline 暴露，乘以因子收益。如无因子数据则跳过。
- **交互效应**：总收益差 - 以上三项之和（残差）。

### 统计显著性

- 1000 次 bootstrap 自助法对日收益序列重采样。
- 计算收益差分布，输出 p 值（双侧）。
- p < 0.05 标注"统计显著"，p ≥ 0.05 标注"统计不显著"。

### 稳健性检查

将回测区间等分为前/中/后三段子区间，检查收益差方向是否一致。
