# 本地研究平台重构技术实施方案

## Why
当前仓库已有本地优先研究平台雏形，但零散的研究脚本、回测数据、A/B 实验、策略变体、报告文档和 Skill 工作流需要统一到一套长期可维护的架构中。

## What Changes
- 5 层架构（策略库、数据中心、流程编排层、研究工具库、文档报告库）
- 中央工具注册 + Git 受控自动化 + 治理审计防漂移 + 完整测试体系
- 分 7 个 Phase 实施：架构和治理入口、数据中心、策略变体库、结构变体合并、流程工具库、文档报告索引、测试审计强化

## Impact
不推翻现有平台，把零散能力归入统一架构。历史数据和历史报告不强制物理搬迁。新工具必须有 README、CLI 示例、输入输出说明和测试。
