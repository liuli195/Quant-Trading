- **研究主题**: 在保留现有信号框架的前提下，减少被动现金，提高有效风险预算利用率

## 1. 研究目标

本轮不追求“无条件满仓”，而是回答三个更具体的问题：

1. 当前策略留下的现金，分别来自哪些模块？
2. 哪些现金属于真正的风险控制结果，哪些现金只是乘法链叠加后的被动残留？
3. 在不直接改成近满仓策略的前提下，能否把一部分被动现金重新转化为有信号支撑的仓位？

本轮优化的直接目标是：

- 提高平均目标仓位和中位目标仓位
- 减少全空仓与低仓信号
- 提升上涨阶段，尤其是反弹阶段的收益捕获
- 保持结论可解释，避免把多个结构性改动一次混在一起

## 2. 已知事实

### 2.1 当前现金状态

| 指标 | 当前结果 |
|---|---:|
| 调仓信号平均目标仓位 | `56.0%` |
| 调仓信号平均现金 | `44.0%` |
| 调仓信号中位目标仓位 | `60.0%` |
| 全空仓信号 | `19` 次 |
| 接近满仓信号 | `2` 次 |
| `PortfolioVolScale < 1` | `199 / 272` 次 |
| `PortfolioVolScale < 0.5` | `52 / 272` 次 |

### 2.2 当前现金形成链路

当前主流程为：

```text
TrendGate
-> RPWeight
-> MomentumTilt
-> RSRSTilt
-> TiltedWeight
-> CrowdPenalty
-> PortfolioVolScale
-> FinalWeight
```

其中，动量与 RSRS 倾斜在活跃资产内重新归一化，不创造现金；真正会降低总仓位的是：

| 层级 | 现金形成方式 |
|---|---|
| 趋势门槛 | 资产未通过门槛时直接归零 |
| 拥挤度惩罚 | 单资产权重被打折，之后不重新归一化 |
| 组合波动率 | `PortfolioVolScale` 整体缩仓，且只缩不放 |
| 交易约束 | `MinWeight` 裁掉小仓位；总仓位缩放后也不重新归一化 |

### 2.3 与高收益对照策略的差异

动态再平衡策略的收益优势，核心并不来自单个因子，而是来自更高、也更稳定的在场率：

| 指标 | 因子轮动 | 动态再平衡 |
|---|---:|---:|
| 持仓日平均总仓位 | `54.58%` | `98.49%` |
| 总仓位低于 `50%` 的持仓日 | `435` | `0` |
| 总仓位高于 `90%` 的持仓日 | `10` | `1289` |
| 年化收益 | `9.85%` | `21.73%` |

现有证据说明：若后续目标转向“提高收益”，因子轮动最值得补的不是小幅调参，而是有效风险预算利用率。

## 3. 研究边界

### 3.1 本轮先做的事

- 拆清现金来源
- 先研究两类最小结构改动：
  - 趋势门槛从硬开关改为软门槛
  - 将一部分拥挤度产生的现金重新分配给仍然有效的资产
- 在第一轮改动有正向结果后，再重新评估 `TargetVol`

### 3.2 本轮暂不做的事

- 不直接取消趋势门槛
- 不直接把所有惩罚后的权重强行归一到满仓
- 不先改 `TopK`、动量、RSRS 或拥挤度核心定义
- 不先把 `TargetVol` 继续上调作为主线
- 不先做“基础仓位 + 轮动倾斜”的大版本重构

## 4. 研究假设

| 编号 | 假设 | 解释 |
|---|---|---|
| `H1` | 硬趋势门槛造成了可优化的低仓与空仓 | 当前门槛是 `0/1`，接近均线时也会直接归零 |
| `H2` | 拥挤度惩罚后的全部现金都保留为现金，可能过于保守 | 尤其在仍有其他低惩罚活跃资产时，部分现金可以继续工作 |
| `H3` | `VolScale` 不是第一优先级 | 已有 `TargetVol` 扫描显示 `0.08` 是现有结构下的效率峰值 |
| `H4` | `MinWeight` 不是主要矛盾 | 历史归因中仅裁掉 `12` 个小仓位，解释力有限 |

## 5. Phase 0：现金来源拆解

### 5.1 目标

在正式改策略前，先用现有审计日志把每次调仓的现金来源拆开，避免后续把问题归错层。

### 5.2 需要重建的中间量

| 字段 | 含义 |
|---|---|
| `sum_tilted` | 倾斜后、任何总仓位控制前的活跃资产权重合计 |
| `sum_after_trend` | 趋势门槛后的权重合计 |
| `sum_after_crowd` | 拥挤度惩罚后的权重合计 |
| `sum_after_volscale` | 组合波动率缩放后的权重合计 |
| `sum_final` | 交易约束后的最终目标仓位 |

### 5.3 现金归因口径

| 来源 | 计算 |
|---|---|
| 趋势门槛现金 | `sum_tilted - sum_after_trend` |
| 拥挤度现金 | `sum_after_trend - sum_after_crowd` |
| 波动率现金 | `sum_after_crowd - sum_after_volscale` |
| 约束现金 | `sum_after_volscale - sum_final` |

### 5.4 Phase 0 产物

| 产物 | 内容 |
|---|---|
| `cash_decomposition.csv` | 每次调仓的四类现金来源 |
| `cash_decomposition_summary.md` | 全样本与分年度摘要 |
| `cash_state_breakdown.csv` | 按年份、仓位分位、是否全空仓切片 |

### 5.5 Phase 0 通过标准

- 可以复现平均目标仓位 `56.0%`
- 四类现金来源之和可以解释总现金
- 能明确回答哪两层解释了大部分现金

## 6. Phase 1：最小结构改动

### 6.1 研究问题

先只回答两个问题：

1. 把趋势门槛从硬开关改成软门槛，能否减少不必要的空仓？
2. 在不废掉拥挤度信号的前提下，回收部分拥挤度现金，能否提高收益捕获？

### 6.2 方案 A：软趋势门槛

当前趋势门槛是：

```text
close >= MA -> 1
close < MA  -> 0
```

建议测试改为区间映射：

```text
close / MA <= lower_bound -> 0
close / MA >= 1.00        -> 1
中间区间线性插值
```

首轮候选：

| 变体 | `lower_bound` |
|---|---:|
| `soft-098` | `0.98` |
| `soft-097` | `0.97` |
| `soft-095` | `0.95` |

预期效果：

- 减少“刚跌破均线就完全退出”
- 提高反弹初段的参与度
- 减少全空仓与低仓信号

### 6.3 方案 B：拥挤度现金部分回收

当前实现中，拥挤度惩罚会直接压低单资产权重，剩余部分全部保留为现金。

建议首轮只回收一部分现金，并且只分配给：

- 当前仍为活跃资产
- 拥挤度惩罚相对较轻
- 未触发单资产上限

首轮候选：

| 变体 | 回收比例 |
|---|---:|
| `recycle-025` | `25%` |
| `recycle-050` | `50%` |
| `recycle-100` | `100%` |

首轮不建议直接把被重罚资产原样加回，因为那会让拥挤度模块失去意义。

### 6.4 首轮 A/B 矩阵

先控制在 6 个变体内：

| 变体 | 目的 |
|---|---|
| `baseline` | 当前正式策略 |
| `soft-097` | 观察软趋势本身 |
| `recycle-050` | 观察现金回收本身 |
| `soft-097_recycle-050` | 观察两者是否叠加 |
| `soft-098_recycle-050` | 更保守的软趋势组合 |
| `soft-097_recycle-025` | 更保守的现金回收组合 |

若这 6 个变体中没有明显优于 baseline 的方案，本轮不应直接扩大网格，而应先复核 Phase 0 的现金归因结论。

## 7. Phase 2：参数细化

只有在 Phase 1 证明某条线有效后，才进入参数细化。

### 7.1 若软趋势有效

围绕最优区间继续扫描：

| 候选 | 说明 |
|---|---|
| `0.96 / 0.97 / 0.98` | 继续确认最优线性过渡带 |
| 分段型软门槛 | 比较“近均线缓降、远离均线快速降权”是否优于单一线性映射 |

### 7.2 若现金回收有效

围绕最优回收比例继续扫描：

| 候选 | 说明 |
|---|---|
| `25% / 50% / 75% / 100%` | 找到收益与信号保真之间的折中 |
| `all-active` | 按活跃资产比例回收 |
| `low-penalty-only` | 只回收给低惩罚资产 |
| `best-signal-only` | 只回收给相对强信号资产 |

### 7.3 何时重新评估 `TargetVol`

只有在趋势门槛与现金回收机制先定下来后，才重新做：

| 候选 | 角色 |
|---|---|
| `0.08` | 当前正式 baseline |
| `0.10` | 适度提高总风险预算 |
| `0.12` | 激进对照 |

原因是：如果先调 `TargetVol`，会把“结构造成的被动现金”和“主动风险预算”混在一起，结论不清楚。

## 8. Phase 3：结构升级备选

若 Phase 1 和 Phase 2 后，平均仓位仍明显偏低，再考虑进入更大改造。

### 8.1 最低总仓位机制

前提：至少存在一个趋势有效资产。

候选：

| 变体 | 总仓位下限 |
|---|---:|
| `floor-060` | `60%` |
| `floor-070` | `70%` |
| `floor-080` | `80%` |

这条线最直接，但也最容易改变策略性格，因此应放在后面。

### 8.2 基础仓位 + 轮动倾斜

把组合拆成两层：

1. 基础仓位层：保持一定常驻暴露
2. 倾斜层：由当前趋势、动量、RSRS、拥挤度决定相对加减

这会更接近动态再平衡的收益结构，但已属于新版本策略，不应与本轮小优化混在一起。

### 8.3 现金替代资产

若研究目标转向“减少闲置资金”而非“增加风险暴露”，可另行研究短债 ETF 或货币类 ETF 作为现金替代。

该方向与本轮“提高有效风险预算”不是同一个问题，建议单独立项。

### 9.2 解释性指标

| 指标 | 用途 |
|---|---|
| 新增仓位来源分解 | 判断新增仓位主要来自哪一层现金回收 |

| 滚动 `252` 日 Sharpe 胜率 | 判断改善是否稳定 |
| 配对 bootstrap | 判断日频路径改善是否只是噪音 |

## 10. 决策门槛

### 10.1 进入下一阶段的门槛

候选方案至少同时满足：

- 平均目标仓位提升 `>= 8pp`
- 年化收益高于 baseline
- `2023-2025` 总收益不低于 baseline
- 新增收益不由单一 ETF 解释超过 `70%`
- 全空仓信号不增加

### 10.2 只保留观察、不升级的情况

出现以下任一情况时，只形成观察结论：

- 仓位明显提高，但收益没有改善
- 收益改善只来自黄金或单一年份
- 滚动窗口胜率接近 `50%`
- 候选只优于 baseline，但不优于更简单的方案

### 10.3 停止规则

出现以下任一情况，本轮不再继续扩大复杂度：

- Phase 1 的最小改动已经能解释主要改善
- 现金回收后收益没有提升，只是提高了仓位
- 软趋势收益主要来自一次尾段反弹，年度分布不稳
- 去掉单一 ETF 后，方案排序完全翻转

## 12. 推荐执行顺序

1. 先做 Phase 0，确认现金主要来自哪两层
2. 再做 Phase 1，先测 `soft trend` 与 `cash recycle`
3. 只有当 Phase 1 有正向结果时，才进入参数细化
4. 软趋势与现金回收机制稳定后，再重新扫描 `TargetVol`
5. 若平均仓位仍明显偏低，再讨论最低总仓位或双层框架

## 13. 当前最可能的结论路径

基于现有证据，最可能成立的路径不是“直接把仓位推满”，而是：

1. 硬趋势门槛确实制造了部分过度空仓
2. 拥挤度惩罚后的全部现金保留，可能让收益侧过于保守
3. 先做软趋势，再做部分现金回收，可能是最容易获得稳定改进的两步
4. `TargetVol` 应在新结构确定后重新校准，而不是先被当成主旋钮

如果这条路径被证实，正式策略的下一步改动更可能是：

- 保留趋势门槛，但从硬开关改为软门槛
- 保留拥挤度惩罚，但只保留其“相对降权”功能，不让全部被扣仓位永久变成现金
- 在新的仓位结构下，再重新确认组合目标波动率
