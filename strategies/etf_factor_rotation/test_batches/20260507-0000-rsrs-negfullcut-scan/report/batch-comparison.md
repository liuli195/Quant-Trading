## 趋势分析

### 1. 收益单调递增（意料之中）

NFC 越大 → 减仓乘数越温和 → 持有仓位更高 → 在市场上涨阶段收益更多。年化收益从 8.71%（NFC=1.0）单调递增至 10.24%（NFC=2.0），提升 1.53 个百分点。每单位 NFC 提升约贡献 0.38% 年化收益。

### 2. 最大回撤不升反降（反直觉）

NFC 越大，RSRS 修正的敏感度越低，直觉上回撤应更大。但实际数据显示回撤从 10.17%（NFC=1.0）下降至 9.52%（NFC=2.0）。这并非矛盾——RSRS 信号本质上是均值回复性质的：过于敏感的修正（NFC 小）会在市场短暂下跌时就大幅减仓，反而可能错过后续反弹，导致"割在最低点 + 追高买回"的负面影响。温和的修正（NFC 大）让持仓更稳定，反而控制了回撤。

### 3. 夏普比率提升显著

夏普从 0.485 → 0.623，提升 28.5%。收益大幅提升的同时波动率几乎不变（0.097 → 0.100），说明风险调整后收益明显改善。

### 4. 边际增益分析（1.6/1.7 补充后更精确）

按区间划分的边际贡献：

| 区间 | 年化收益增量 | 夏普增量 |
|------|-------------|----------|
| 1.0 → 1.2 | +0.19% | +0.015 |
| 1.2 → 1.5 | +0.52% | +0.046 |
| 1.5 → 1.6 | +0.15% | +0.013 |
| 1.6 → 1.7 | +0.26% | +0.026 |
| 1.7 → 1.8 | +0.24% | +0.023 |
| 1.8 → 2.0 | +0.17% | +0.015 |

1.5 → 1.6 区间增量最小（+0.15%），1.6 → 1.7 → 1.8 增量回升（+0.24~0.26%），1.8 → 2.0 再次衰减。**NFC=1.8 仍是综合最优，但 1.7 非常接近（胜率最高 73.9%）。**

### 5. 贝塔基本稳定

贝塔在 0.173~0.183 之间，始终是低贝塔策略（市场暴露 ~18%），说明 RSRS 修正参数不改变策略的市场中性属性。

### 6. 胜率在 NFC=1.7 处见顶

胜率从 69.4%（NFC=1.0）持续上升至 73.9%（NFC=1.7），之后微降至 73.1%（NFC=2.0）。NFC=1.7 的胜率×盈亏比综合最优，NFC=1.8 的绝对收益和夏普最优。

**首选 NFC=1.8，次选 NFC=1.7**（当前默认 1.0）：

| 指标 | NFC=1.7 | NFC=1.8 | 差异 |

- **NFC=1.8**：综合风险收益比最优，年化首破 10%，夏普首破 0.6

- 两者差距很小，实战差异可忽略；建议**取 NFC=1.8 为默认值**

如果偏好保守风格，NFC=1.5（年化 9.42%、夏普 0.546、回撤 10.12%）仍是稳健选择。
