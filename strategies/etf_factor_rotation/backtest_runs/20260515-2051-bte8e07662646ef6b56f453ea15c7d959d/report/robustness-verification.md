# 稳健性验证：黄金 CrowdStart 0.60 → 0.80

- **对比**: gold-baseline → gold-start-080
- **交易日数**: 1289
- **回测窗口**: 2021-01-01 → 2026-04-30
- **方法**: 配对 Block Bootstrap (2000 reps, block=40) + 滚动 252日子样本 + 年度分解
- **Seed**: 42

---

## 1. 配对 Block Bootstrap

原假设 H₀: 两策略日均收益无差异（mean(r_baseline - r_variant) = 0）。

将 1288 个对齐交易日按 block=40 分块，重采样 2000 次，估计日均收益差的抽样分布。

| 指标 | 数值 |
|------|------|
| 日均收益差 (baseline - variant) | -0.11 bp |
| 年化收益差 (baseline - variant) | -0.29 pp |
| Bootstrap CI95 (日频) | [-0.47, 0.24] bp |
| p-value (双尾) | 0.2964 |
| 0 在 CI95 内 | 是 — 差异不显著 |

**解读**：CI95 包含 0，p=0.296 > 0.05，意味着在日收益层面，两个策略的差异未达到统计显著。这与 CrowdDiff 的 CI95 普遍含 0 一致——1289 个交易日的样本量不足以在日频产生统计显著差异。但点估计方向正确（variant 日频领先 0.1 bp，年化 0.29 pp），与 AB 层面的 Sharpe/年化收益改善方向一致。

---

## 2. 滚动 252日子样本分析

每个滚动窗口计算 baseline 和 variant 的年化 Sharpe 与年化收益，比较两者的优劣。

| 指标 | 数值 |
|------|------|
| 总滚动窗口数 | 1038 |
| Variant Sharpe > Baseline 比例 | 47.4% |
| Variant 年化收益 > Baseline 比例 | 54.4% |
| 滚动 Sharpe 差均值 | -0.0400 |
| 滚动 年化收益差均值 | 0.11 pp |

### 时间分段

| 时期 | Sharpe差均值 | 年化收益差均值 (pp) | Variant胜率 |
|------|-------------|-------------------|------------|
| 早期 (2022-01 → 2023-06) | +0.0048 | +0.07 | 78.3% |
| 中期 (2023-06 → 2024-11) | -0.0202 | +0.19 | 33.2% |
| 晚期 (2024-11 → 2026-04) | -0.1045 | +0.07 | 30.6% |

**解读**：Variant 在 47% 的滚动窗口中 Sharpe 更高（Baseline 在 53% 窗口中更优），但在 54% 的窗口中年化收益更高。改善方向不单调——早期（2022-2023）胜率高达 78%，但中后期降至 31-33%。这表明 gold-start-080 的优势可能随时间衰减，或集中在特定市场状态中。与子周期分析一致：2021-2023 样本稀疏（惩罚率仅 3.9%），2024-2026 才是差异出现的时期，但此时期的 Sharpe 胜率反而是最低的。

## 4. 综合判定

| 验证层级 | 结果 | 方向 | 解读 |
|----------|------|------|------|
| 配对 Bootstrap | p=0.296, 0∈CI95 | → | 日频差异不显著（p > 0.05），但点估计方向为正向 |
| 滚动子样本 | 47% Sharpe胜率, 54% 收益胜率 | ↓/↑ | 混合信号——Sharpe 视角 baseline 略优，收益视角 variant 略优 |
| 年度分解 | 3/6 年 Sharpe改善，2/6 年恶化 | ↕ | 2023-2024 Variant Sharpe 反而更低，改善不普遍 |
| AB 标准指标 | Sharpe +0.7%, 年化 +0.32pp | ↑ | 点估计优势（原报告） |

**最终评估**：gold-start-080 在日频 bootstrap 和滚动子样本层面均未达到统计显著。改善信号在年度层面不普遍（2023-2024 年 variant Sharpe 低于 baseline），滚动 Sharpe 胜率也不足 50%。结论应降调为 **"全样本点估计方向性支持采用 0.80，但改善幅度小、统计不显著、且存在时间异质性（早期好、中后期弱），建议作为合理参数调整上线并持续监控"**。

**建议**：若需更高置信度，可考虑：
- 额外 holdout 期间验证（如 2026-05 后实盘模拟）
- 或在新的市场周期中重新检验滚动子样本方向的稳定性
