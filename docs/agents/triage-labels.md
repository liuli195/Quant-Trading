# Triage 标签

工程技能使用五类固定 triage 角色。本文件把这些角色映射到本仓库 GitHub label。

| 技能角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给无人值守 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

当技能提到某个 triage 角色时，使用表中对应的 GitHub label。
