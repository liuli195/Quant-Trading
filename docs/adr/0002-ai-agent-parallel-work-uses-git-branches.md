# ADR 0002: 多 AI Agent 并行工作使用 Git 分支

## 状态

Accepted

## 背景

曾评估过“共享工作区 + 任务登记”的方式。它能记录 agent、目标、写入范围和检查证据，但本质是自建低配协作协议，容易变成额外维护负担。

## 决策

多 AI agent 并行写入时，使用 Git 分支、commit、diff、PR 和 review 管理协作，不采用任务登记作为主要机制。

## 影响

- 每个 agent 在独立分支工作。
- 不允许多个 agent 在同一写入分支上并行修改 repo-tracked 文件。
- 所有主干改动必须通过 PR。
- 共享工作区只适合只读探索、临时验证或单 agent 串行工作。
